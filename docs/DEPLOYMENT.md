# Production Deployment Architecture

This guide details recommended deployment architectures for deploying the three tiers of **Study Insights** to cloud providers.

---

## 1. Hosting Architecture Recommendation

| Tier | Recommended Platform | Alternatives | Notes |
|---|---|---|---|
| **Frontend** | Vercel | Cloudflare Pages, Netlify | Static SPA build (`dist/`) with global edge CDN. |
| **Backend** | Render / Railway | AWS ECS, Fly.io, DigitalOcean | Node.js long-running HTTP service. |
| **RAG Server** | Render / Google Cloud Run | Fly.io, AWS App Runner | Containerized FastAPI service with persistent volume for ChromaDB. |
| **Database & Storage** | Supabase Managed Cloud | Self-hosted Supabase | PostgreSQL + Supabase Storage + Auth. |

---

## 2. Environment Variables Checklist

### Frontend (Vercel / Cloudflare)
- `VITE_SUPABASE_URL`: Production Supabase URL.
- `VITE_SUPABASE_PUBLISHABLE_KEY`: Production Supabase publishable anon key.
- `VITE_API_BASE_URL`: Full HTTPS URL of the deployed Node.js backend (e.g. `https://api.studyinsights.com/api`).

### Backend (Render / Railway)
- `NODE_ENV=production`
- `PORT=5000` (or injected by platform)
- `SUPABASE_URL`: Production Supabase URL.
- `SUPABASE_PUBLISHABLE_KEY`: Production anon key.
- `SUPABASE_SERVICE_ROLE_KEY`: Secret service-role key (kept private in environment config).
- `RAG_SERVER_URL`: Private internal VPC or HTTPS URL of the RAG microservice.
- `FRONTEND_URL`: Production domain of your React frontend (e.g. `https://studyinsights.com`).

### RAG Microservice (Render / Cloud Run)
- `ENVIRONMENT=production`
- `PORT=8000`
- `GEMINI_API_KEY`: Production Google AI Gemini API key.
- `GEMINI_MODEL=gemini-3.8-flash`
- `CHROMA_PATH=/var/data/chroma` (mount a persistent disk if deploying on Render/Fly.io).

---

## 3. Production Security Hardening

1. **Strict CORS Policy**: In `backend/src/app.js`, CORS is restricted strictly to `FRONTEND_URL`. Wildcard `*` is disabled in production.
2. **Rate Limiting**: `express-rate-limit` throttles brute force and high-frequency endpoint abuse.
3. **Database RLS**: Every table has Row Level Security enforced via `auth.uid() = user_id`.
4. **Storage Privacy**: The `study-documents` bucket is strictly private; downloads require signed URLs generated by the server.
5. **No Secret Leakage**: Centralized error middleware suppresses raw error stack traces and database internal diagnostics in production mode.
